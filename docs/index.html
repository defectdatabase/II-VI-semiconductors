The DefectDB simulation tool runs live on nanoHUB: build any defect in any II–VI supercell, relax it with our fine-tuned M3GNet force fields (ten models — one per charge state q = −2 … +2 at PBE and HSE fidelity), compute formation energies, CI-NEB migration barriers, and finite-temperature MD. MLFF results live in the tool; every number on this website is pure DFT.

Launch the tool on nanoHUB →

Bulk compounds. 6763 I–III–VI2 chalcopyrites and I2–II–IV–VI4 kesterites/stannites. Ground-state configurations selected from a PBEsol 2×2×1 polymorph screen (21,242 static calculations); production properties from HSE06+SOC (AEXX = 0.25, HFSCREEN = 0.2, LOPTICS) static runs. Formation energy per atom versus elemental references computed at the same level of theory; decomposition energy per formula unit versus the stoichiometric binary decomposition (A2X + BX + CX2 for kesterites; ½(A2X + B2X3) for chalcopyrites) including the ideal-mixing entropy at kBT = 0.0257 eV. Band gaps from eigenvalue band properties; dielectric constant is the electronic (ion-clamped) LOPTICS value at E = 0; SLME from the Shockley–Queisser-like metric (vaspkit), maximum over absorber thickness. Defects. Charged-defect supercells (q = −2 … +2) for CdTe and CdSexTe1−x alloys at PBEsol and HSE+SOC. Ef(q, EF) = Edefect,q − Epristine + Σniμi + q(EVBM + EF) + Ecorr, with chemical potentials at the Cd-rich and Te-rich limits and Kumagai–Oba (eFNV) finite-size corrections. Raw data (~10.8 TB) archived on ALCF Eagle. Citation. M. H. Rahman, Y. Yang, and A. Mannodi-Kanakkithodi, DefectDB: An Open-Source Infrastructure for Defect Thermodynamics in II–VI Semiconductors (2026, in preparation).

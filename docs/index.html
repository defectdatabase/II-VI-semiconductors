Defect Calculator — nanoHUB

Build any defect in any II–VI supercell, relax it with the fine-tuned M3GNet force fields (ten models — one per charge state q = −2 … +2 at PBE and HSE fidelity), compute formation energies, CI-NEB migration barriers and finite-temperature molecular dynamics. Machine-learning results live in the tool; every number on this site is pure DFT.

How every number is produced

Total energy — OSZICAR final free energy F of each run (the convention the production pipeline used; E0 differs by ~0.5 meV/atom). Formation energy — (F − Σniμi)/N against elemental references at the same level of theory. Decomposition energy — stoichiometric decomposition into the local binaries (A2BCX4 → A2X + BX + CX2; ABX2 → ½(A2X + B2X3)) plus the ideal-mixing entropy kBT·Σf ln f at kBT = 0.0257 eV — a fixed binary decomposition, not a convex hull. Band gap — occupied-band counting on EIGENVAL using NELECT. Dielectric constant — electronic, ion-clamped, from the LOPTICS density–density tensor at E = 0. SLME — maximum over absorber thickness of vaspkit's SLME.dat.

Defects

Ef(q, EF) = Edefect,q − Epristine + Σniμi + q(EVBM + EF) + Ecorr, lower envelope over q = −2 … +2. Defect and pristine energies are raw OSZICAR F values; the charge state is read from NELECT, never from the directory name; band edges are recomputed per host from the raw bulk EIGENVAL; chemical potentials come from the archived competing-phase analysis. Kumagai–Oba (eFNV) corrections are carried from the original campaign — the generating script and dielectric tensor were not archived, so they are reproducible in method but not bit-reproducible. Charge states without a correction are held back from the envelope rather than published uncorrected.

Known gaps

No optics anywhere in the PBEsol tree, so dielectric and SLME exist only for HSE06+SOC. HSE+SOC elemental references for Cd, Se and Zn are unconverged, so II–VI hosts carry no HSE+SOC row. CdTe HSE+SOC defect runs were not retained, so those rows come from the campaign table and are labelled as such. The kesterite/stannite defect campaign sits on a parent lattice whose pristine cell is absent from disk, so it is not published yet.

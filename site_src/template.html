The DefectDB simulation tool runs live on nanoHUB: build any defect in any II–VI supercell, relax it with our fine-tuned M3GNet force fields (ten models — one per charge state q = −2 … +2 at PBE and HSE fidelity), compute formation energies, CI-NEB migration barriers, and finite-temperature MD. MLFF results live in the tool; every number on this website is pure DFT.
